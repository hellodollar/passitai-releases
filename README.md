# PassIt AI 桌面版下载

此仓库用于公开分发 PassIt AI 桌面安装包、版本信息与更新说明，不包含桌面客户端源码。

- 官网：https://passitai.com/#desktop
- 安装包与版本记录：https://github.com/hellodollar/passitai-releases/releases

支持 macOS Apple Silicon、macOS Intel 和 Windows x64。只有安装包构建完成并通过完整性检查后，才会发布对应版本；尚未发布的版本不会提供下载。

目前 macOS 安装包使用 ad-hoc 签名，尚未进行 Apple 公证；Windows 安装包尚未进行代码签名。
